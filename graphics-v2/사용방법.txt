바다 찌낚시 그래픽 개선 V2

시연 방법
1. ZIP 전체 압축 해제.
2. fishing-demo.html을 Chrome 또는 Edge에서 열기.
   같은 폴더에서 PowerShell: Start-Process .\fishing-demo.html
3. 오른쪽 시연 패널: 낮 / 노을 / 밤, 맑음 / 거친 바다 / 비.
4. 방파제 / 갯바위 / 여밭은 캐스팅 전 대기 상태에서 전환 가능.
   시연용으로 레벨 잠금과 관계없이 이동합니다. 출시 소스에는 적용되지 않습니다.
5. 원본 비교 / 화면 감상 버튼 제공.
6. 던지기를 누르고 초록 구간에서 다시 누르세요.
7. 느리면 상단 고화질 버튼을 눌러 절전 모드로 전환하세요.

추가 개선
- 갯바위 층리와 실루엣, 주변 바위와 작은 돌.
- 방파제 난간, 바닥 줄눈, 가장자리 무늬.
- 쿨러 손잡이와 잠금쇠, 미끼 트레이, 낚시 소품.
- 조끼 주머니/지퍼, 선글라스, 릴 구조, 낚싯대 곡선 분할.
- 물고기 몸통 분할 및 비늘 색 표현.
- 바다 미세 물결, 해안 물결 링, 장비의 하늘 반사.
- 모바일 그림자 샘플 간격 수정.
- 원본 테트라포드 중심부 좌표 오류 수정.

직접 생성한 절차적 모델/셰이더로 구현했으며 외부 유료 자료나 AI 서비스가 필요 없습니다.
사진 같은 사실적 그래픽을 완성한 버전은 아닙니다.
실제 토스 광고는 시연에 연결되어 있지 않습니다.
토스 프로젝트는 ait-project 폴더에 있습니다. 기존 연결/게임 규칙을 유지했습니다.
시연 데이터는 원본 게임과 별도로 저장됩니다.

검증
- 원본/개선/로더 JavaScript 구문 검사.
- GLES3 셰이더 16개 컴파일, 8개 프로그램 연결 통과.
- 29개 포인트/낚시꾼/찌/26종 물고기: 유한 좌표 및 인덱스 검사 통과.
환경 제한으로 실제 브라우저 화면/조작/프레임과 토스 SDK 빌드는 검증하지 못했습니다.
