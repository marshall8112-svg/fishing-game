# 바다 찌낚시 그래픽 V2

`fishing-demo.html`을 Chrome 또는 Edge에서 열어 시연합니다. 설치가 필요 없습니다.

PowerShell:
```powershell
Start-Process .\fishing-demo.html
```

낮·노을·밤, 날씨, 방파제·갯바위·여밭 전환과 원본 비교를 제공합니다. 포인트 전환은 캐스팅 전 대기 상태에서 사용합니다.

`ait-project/`는 수정된 앱인토스 프로젝트입니다. 상세 안내는 `사용방법.txt`를 참조하세요.

검증: JavaScript 문법, GLES3 셰이더 16개 컴파일 및 8개 프로그램 연결, 29개 포인트·26종 물고기 등의 좌표·인덱스 검사 통과. 실제 브라우저 렌더링·조작·성능과 토스 SDK 빌드는 미검증입니다.
